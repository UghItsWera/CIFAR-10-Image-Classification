# CIFAR-10-Image-Classification using Convolutional Neural Netwroks (PyTorch)

Implemented a Convolutional Neural Network (CNN) using PyTorch to perform multi-class image classification on the CIFAR-10 dataset. The model architecture consists of stacked convolutional and pooling layers for feature extraction, followed by fully connected layers for classification.

The project includes end-to-end pipeline development: data preprocessing and normalization, model training on GPU/CPU, performance evaluation on a test set, and visualization of training/testing loss and accuracy over time. Multiple training configurations (10 and 30 epochs) were explored to analyse model convergence and performance trends.
